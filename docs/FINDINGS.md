# Findings — журнал знахідок

Аналог OB-журналу IDENN. Аномальна цифра, дивне placement-рішення,
несподівана entropy у Brio, збій, розбіжність документації з кодом — новий
рядок FN-NNN одразу в момент знахідки. Кейс живе в репо, не в чаті.

Формат рядка:

```
FN-NNN | YYYY-MM-DD | фаза/контекст | суть (1-2 речення) | статус
```

Статуси: `open` → `closed` / `expanded` (розширено брифом) / `wontfix`.
Правила тріажу — AGENTS.md. Перед кожним брифом відкриті кейси перечитуються;
бриф або закриває/розширює кейс, або явно заносить його в не-цілі.
